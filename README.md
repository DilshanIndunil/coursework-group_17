#coursework-group_17 

A full-featured e-commerce web application built using the MERN stack (MongoDB, Express.js, React, and Node.js), with Docker integration for containerization and easier deployment. This project provides a seamless online shopping experience with features like product browsing, user authentication, shopping cart management, and admin functionalities. Docker ensures a consistent development environment across different systems and simplifies deployment, allowing the app to run reliably in any environment.
